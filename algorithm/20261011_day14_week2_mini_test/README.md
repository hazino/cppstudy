# Day 14 — 2026-10-11: Mini Test

## 오늘의 목표

제한 시간 안에 풀 문제를 고르고, 자동완성 없이 분석·구현·검증한다.

## 핵심 개념

문제 분석, 풀 문제 선택, 시간 배분.

## No IntelliSense Drill

기본 입출력부터 필요한 코드를 자동완성 없이 작성한다.

브라우저에서 문제 탭만 열고 유형 태그·강의·힌트·해설·AI·기존 예제를 닫는다. 유형별 출제표는 제공하지 않는다. CodeTree 링크의 단원 제목도 가리고, 이미 풀었던 문항은 익숙한 문제로 별도 기록한다.

[플랫폼별 제출·로컬 검증 방법](../README.md#플랫폼별-제출과-로컬-검증)을 따른다. 온라인 문제의 전체 지문은 저장소에 복사하지 않는다.

## 권장 시간

105분 연속 테스트: 전체 읽기 5분 + 문제별 권장 30분씩 + 검증 10분. 이후 15분 기록. 90~120분으로 조정 가능하며 120분을 선택하면 기록은 Day 15에 한다.

## 자주 하는 실수

풀이 순서 고정, 검증 시간 미확보, 분석 없이 구현.
