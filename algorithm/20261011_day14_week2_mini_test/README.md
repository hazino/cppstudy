## 오늘의 목표

제한 시간 안에 풀 문제를 고르고, 자동완성 없이 분석·구현·검증한다.

## 권장 시간

권장: 연속 105분 테스트(전체 읽기 5분 + 풀이 90분 + 검증 10분), 회고 15분. 90~120분 중 미리 시간을 정한다. 120분 테스트를 선택하면 회고는 Day 15에 한다.

## 자주 발생하는 실수
