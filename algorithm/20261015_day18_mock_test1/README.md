[플랫폼별 제출·로컬 검증 방법](../README.md#플랫폼별-제출과-로컬-검증)을 따른다. 온라인 문제의 전체 지문은 저장소에 복사하지 않는다.

## 권장 시간

120분 연속 테스트: 전체 읽기·순서 결정 10분 + 풀이 95분 + 검증 15분. 표의 시간은 목표 배분이며, 40분 이상 막히면 전환한다. 5문제 완주보다 선택·전환·정확도를 평가하고 회고는 Day 19에 한다.

## 자주 하는 실수

한 문제에 집착, 제출 전 확인 누락, 시간 관리 실패.
