# 로컬 검증 자료

첫 풀이는 온라인 브라우저에서 작성한다. 전체 문제 지문은 복사하지 않는다.

- CodeTree: 직접 만든 입력을 `practice_01_edge.txt`, 예상 출력을 `.out`으로 저장한다. 기존 루트의 `input.txt`는 개념 예제용이다.
- Programmers: 함수 인자와 예상 반환값을 기록한다. 사이트의 배열 표기 그대로를 표준 입력으로 리다이렉트하지 않는다.
- 함수 제출 문제의 로컬 검증은 학습 후 `main()`에서 `solution(...)`을 호출하도록 직접 작성한다. 온라인에는 `main()`을 제출하지 않는다.
- skeleton은 의도적으로 미완성이며 실행 성공만으로 정답을 판정하지 않는다.

```bash
# 날짜 폴더에서, 표준 입출력 풀이와 입력 파일을 작성한 뒤
../run.sh practice_01.cpp input/practice_01_edge.txt
```

파일명이 q1.cpp/a.cpp 등인 실전 폴더에서는 실제 파일명으로 바꿔 실행한다.
