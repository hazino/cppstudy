## 기본 구조
```
Graph → Start Node → BFS / DFS → Visited 관리 → 탐색
```

## BFS vs DFS
| | BFS | DFS |
|---|---|---|
| 자료구조 | queue | 재귀 / stack |
| 특징 | 가까운 것부터 (레벨 순서) | 한 방향으로 끝까지 |
| 주 용도 | **가중치 없는 최단거리** | 연결 여부, 경로 전체 탐색, 백트래킹 |
| 복잡도 | O(V + E) | O(V + E) |
