## Backtracking 기본 Template
```cpp
void dfs(int depth /* 상태 */) {
    if (종료 조건) { 결과 처리; return; }
    for (선택지 : 후보들) {
        if (불가능) continue;   // Pruning
        선택;                   // 상태 변경
        dfs(depth + 1);
        선택 취소;              // 상태 복구
    }
}
```

## 경우의 수 감각 (1초 ≈ 10^8 연산)
| 탐색 | 개수 | 가능한 N |
|---|---|---|
| 순열 N! | 10! ≈ 3.6×10^6 | N ≤ 10 |
| 부분 집합 2^N | 2^20 ≈ 10^6 | N ≤ 20 |
| 조합 nCr | 20C10 ≈ 1.8×10^5 | N ≤ 25 정도 |
