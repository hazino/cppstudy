### 성적 평균 유형 (개념만)

구간 [l,r] 합은 S[r]-S[l-1], 평균은 그 합을 구간 길이로 나눈 값이다. 전처리 O(N), 질의 O(1). 실수 변환 시점과 요구 소수 자릿수를 확인한다. 과거 Softeer `성적 평균`과 같은 구간 질의 연습이며 별도의 정답 코드는 제공하지 않는다.
