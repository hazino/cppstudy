## 입력 크기 → 허용 복잡도 (대략적인 참고)
| N | 복잡도 | 대표 알고리즘 |
|---|---|---|
| ≤ 10 | O(N!) | 순열 완전 탐색 |
| ≤ 20 | O(2^N) | 부분 집합, 비트마스크 |
| ≤ 500 | O(N³) | Floyd-Warshall, 3중 루프 DP |
| ≤ 5,000 | O(N²) | 2중 루프 DP |
| ≤ 10^6 | O(N log N) | 정렬, 이분 탐색, Dijkstra, 우선순위 큐 |
| 큰 N | O(N)도 시간·메모리 검토 필요 | 입력 자체의 비용 확인 |
| > 10^8 | O(log N) | 이분 탐색, 수학 |
