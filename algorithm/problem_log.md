# 문제풀이 기록

문제를 풀 때마다 아래 블록을 복사해서 맨 아래에 추가한다.

```text
Date:
Platform: CodeTree / Programmers / LeetCode (선택)
Problem: 이름 / URL
Difficulty:
Result: 성공 / 부분 성공 / 실패 / 로컬 검증만 완료
Time: 분석 / 구현 / 디버깅 / 총 시간
First Approach:
Selected Algorithm:
Correct Algorithm:
Why I Failed / Struggled:
Implementation Mistake:
Time Complexity:
What I Learned:
Retry Date: 예정일 / 실제 재도전일 / 결과
```

실패 원인은 복수 선택하고 구체적인 재현 입력을 함께 적는다.

- Algorithm Knowledge — 알고리즘 지식 부족
- Algorithm Selection — 알고리즘 선택 실패
- Implementation — 구현 실수
- STL Syntax — STL 문법 실수
- Edge Case — 경계 사례 누락
- Time Complexity — 시간복잡도 판단 실패
- Debugging — 디버깅 전략 실패
- Time Management — 시간 관리 실패

힌트·해설 사용 시점과 자동완성 없이 풀었는지도 기록한다. Retry Date는 예를 들어 2일 후와 7일 후로 잡고, 재풀이 결과까지 갱신한다.
